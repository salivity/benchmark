PCMark 10 Applications Battery Rundown Testing Methodology

This article outlines the standardized methodology for benchmarking laptop battery life using the PCMark 10 Applications battery rundown test. It covers the essential steps required to achieve accurate and repeatable results, including system preparation, hardware calibration, software prerequisites, test execution, and data retrieval. By following this guide, hardware testers can reliably measure a computer's battery longevity under realistic productivity workloads.

Software Prerequisites

Unlike standard synthetic benchmarks, the PCMark 10 Applications test uses real-world software to measure battery drain. Before beginning, you must install the following:

  • PCMark 10: You must have the Professional Edition (or a version that explicitly includes the Battery Life benchmark suite) installed and updated to the latest version.
  • Microsoft Office: A licensed and activated version of Microsoft Office (2013 or newer) is required. Word, Excel, and PowerPoint must be installed, opened at least once, and have all initial setup prompts dismissed.
  • Microsoft Edge: Ensure the browser is installed, updated, and has had its first-run experience completed.

System Preparation

To ensure the benchmark measures only the intended workload, the operating system must be stabilized to prevent background interruptions.

  1. Update the System: Install all pending Windows updates and hardware drivers (especially GPU and chipset drivers). Reboot the system to finalize installations.
  2. Disable Background Processes: Close and disable all non-essential third-party applications in the system tray, such as cloud storage sync clients (OneDrive, Dropbox), game launchers (Steam), and communication tools.
  3. Pause Security Scans: Temporarily disable scheduled antivirus scans and Windows Update automatic downloads so they do not trigger during the test and skew the CPU usage.
  4. Clear Temp Files: Ensure the primary storage drive has at least 20GB of free space for temporary benchmark files.

Hardware and Power Calibration

Screen brightness and power states are the largest variables in battery testing. They must be strictly controlled for apples-to-apples comparisons across different hardware.

  • Calibrate Display Brightness: Use a colorimeter or luminance meter to set the display brightness to a standardized level, typically 150 nits or 200 nits.
  • Disable Adaptive Brightness: Turn off Windows adaptive brightness, Content Adaptive Brightness Control (CABC) in graphics control panels, and any ambient light sensors.
  • Configure Windows Power Settings:
    • Set the Windows Power Mode to "Balanced" or the manufacturer’s default out-of-the-box profile.
    • Set "Turn off the display" to Never when on battery power.
    • Set "Put the computer to sleep" to Never when on battery power.
    • Set the critical battery action to Hibernate at 5% (or the lowest level the OS allows).
    • Disable the Windows "Battery Saver" mode so the screen does not automatically dim at 20% capacity.
  • Keyboard Backlight: Turn off the keyboard backlight completely.
  • Peripherals and Audio: Unplug all external USB devices, mice, and drives. Mute the system audio.
  • Network State: Either enable Airplane Mode or connect to a local Wi-Fi network that has no internet access. This standardizes radio power draw while preventing random background internet traffic.

Executing the Benchmark

Once the system is calibrated and prepared, follow these steps to run the rundown test:

  1. Charge to Full: Plug in the AC adapter and charge the laptop battery until it reaches 100% capacity. Leave it plugged in for an additional 30 minutes to ensure the battery cells are fully saturated.
  2. Launch PCMark 10: Open the application and navigate to the Benchmarks tab.
  3. Select the Test: Choose Battery Life from the menu, and select the Applications profile.
  4. Start the Run: Click the Run button. Immediately unplug the AC power adapter when prompted (or right before clicking Run, depending on the software version prompt).
  5. Leave the System Unattended: The benchmark will now loop continuously. A single loop takes roughly 10 minutes, cycling through tasks in Word, Excel, PowerPoint, and Edge, followed by a brief idle period. Do not touch the mouse or keyboard while the test is active.

Collecting the Results

The test will automatically repeat the workload loop until the battery depletes to its critical threshold (usually 5% or lower) and forces the system into hibernation or shutdown.

  1. Reconnect Power: Plug the AC adapter back into the laptop and turn the system on.
  2. Recover the Data: Once Windows boots, open PCMark 10. The software automatically saves the progress after every completed loop.
  3. Record the Metrics: PCMark 10 will compile the interrupted run data and display the final results. Record the two primary metrics provided:
    • Battery Life Duration: Expressed in hours and minutes, indicating how long the system lasted.
    • Overall Performance Score: Indicates how fast the system completed the Office and Edge tasks while running on battery power, revealing if the hardware throttles performance when unplugged.
