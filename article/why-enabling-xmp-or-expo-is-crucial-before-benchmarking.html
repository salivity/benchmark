Why Enabling XMP or EXPO is Crucial Before Benchmarking

This article provides a quick overview of why verifying the activation of Intel XMP or AMD EXPO memory profiles is a mandatory step before benchmarking computer hardware. By exploring how default RAM speeds create artificial bottlenecks, skew CPU and GPU metrics, and ruin comparative data, this guide explains how failing to enable these profiles invalidates benchmark results and misrepresents a system's true capabilities.

Bypassing Default Memory Speeds

Out of the box, system memory (RAM) does not run at the high speeds printed on its retail packaging. Instead, motherboards default to baseline JEDEC standards—typically 2133 MHz for DDR4 or 4800 MHz for DDR5—to ensure the system can boot safely. Intel’s Extreme Memory Profile (XMP) and AMD’s Extended Profiles for Overclocking (EXPO) are built-in BIOS configurations that automatically set the correct voltage, frequency, and timings required for your RAM to run at its advertised performance levels.

Eliminating Artificial CPU Bottlenecks

Modern processors rely heavily on fast memory to feed data to their cores. Without XMP or EXPO enabled, the CPU is forced to wait longer for data transfers, resulting in wasted clock cycles. This is especially critical for architectures like AMD Ryzen, where the internal communication speed between CPU cores (Infinity Fabric) is directly tied to the speed of the system memory. Benchmarking a CPU with baseline RAM speeds will yield artificially low single-core and multi-core scores that do not reflect the processor's actual power.

Ensuring Accurate GPU Testing

Although graphics cards have their own dedicated video memory (VRAM), they still depend on the CPU and system RAM to process game logic and prepare frames for rendering. When system memory runs at slow default speeds, the CPU cannot feed instructions to the GPU fast enough. In gaming benchmarks, this creates a bottleneck that lowers average frame rates and drastically worsens 1% and 0.1% low frame times. If you benchmark a graphics card without XMP or EXPO active, you may mistakenly conclude the GPU is underperforming when the system RAM is the actual limiting factor.

Maintaining Valid Comparative Data

The primary purpose of benchmarking is to compare your system’s performance against other similar setups to ensure your hardware is functioning correctly. Almost all professional hardware reviewers, manufacturers, and public benchmark databases test systems with XMP or EXPO enabled. If your profiles are disabled, you are not conducting an apples-to-apples comparison. Your scores will fall significantly below the expected average, making it impossible to accurately diagnose genuine issues like thermal throttling or defective components.

Guarding Against Silent BIOS Resets

Enabling XMP or EXPO once during the initial PC build is not sufficient; it must be verified before every benchmarking session. Motherboard BIOS updates, unexpected power outages, unstable overclocks, or minor hardware changes can trigger a safety mechanism that silently resets the BIOS to its factory defaults. Taking a few seconds to check the Windows Task Manager or a utility like CPU-Z before running a test guarantees your memory is running at its rated speed, ensuring your benchmark results are valid and reliable.
