The Purpose of Unigine Heaven and Superposition Benchmarks

This article explains the primary functions of the Unigine Heaven and Superposition benchmarking suites in evaluating computer graphics hardware. It details how these tools are used by PC enthusiasts, builders, and technicians to measure rendering performance, validate overclocking stability, test thermal cooling solutions, and compare different graphics processing units (GPUs) using standardized scoring systems.

Measuring Raw GPU Performance

The primary purpose of both Unigine Heaven and Superposition is to measure the rendering capabilities of a GPU. As synthetic benchmarks, they run a pre-rendered, real-time 3D environment that places a consistent, heavy workload on the graphics card.

At the end of a benchmark run, the software provides an overall score along with minimum, maximum, and average frames per second (FPS). Because the workload is identical every time, users can use these metrics to:

  • Compare the performance of their GPU against other models using online leaderboards.
  • Verify that a newly installed graphics card is performing as expected.
  • Measure the exact percentage of performance gained after a hardware upgrade or driver update.

Validating Overclocking Stability

When users overclock a GPU (increasing its core and memory clock speeds beyond factory settings), the hardware can become unstable. Heaven and Superposition are industry-standard tools for stress-testing these overclocks.

Both suites allow users to run the 3D environment in a continuous, infinite loop. If an overclock is unstable, the benchmark will expose it in one of two ways:

  • Visual Artifacts: Flashes of color, strange geometric shapes, or black spots appearing on the screen, which usually indicate the GPU memory is pushed too far.
  • System Crashes: The benchmark freezing, crashing to the desktop, or causing the computer to restart, indicating the GPU core clock is too high or lacks sufficient voltage.

If a system can run Heaven or Superposition for an hour without crashing or artifacting, the overclock is generally considered stable for daily gaming.

Thermal and Power Testing

Graphics cards generate significant heat and draw maximum power when under full load. Unigine benchmarks push GPU utilization to 99% or 100%, creating a worst-case scenario for heat generation.

System builders use these suites to monitor GPU temperatures and evaluate the effectiveness of a computer's cooling system. By running the benchmark continuously, users can tune their PC case fan curves, test liquid cooling loops, and ensure the GPU does not "thermal throttle" (automatically slow itself down to prevent overheating). It also tests whether the computer's Power Supply Unit (PSU) can handle sustained peak power draw from the graphics card.

The Difference Between Heaven and Superposition

While both tools serve the same fundamental purposes, they target different generations of hardware.

Unigine Heaven (Released in 2009)

  • Focus: DirectX 11 and heavy use of hardware tessellation.
  • Current Use: Because it is an older tool, modern GPUs run it effortlessly. However, it remains popular because it loads quickly, takes up very little storage space, and is still effective for quickly finding instability in core clock overclocks and testing older or budget hardware.

Unigine Superposition (Released in 2017)

  • Focus: Built on the upgraded UNIGINE 2 Engine, it features complex lighting, Screen-Space Ray-Traced Global Illumination (SSRTGI), and high-resolution textures.
  • Current Use: Designed for modern, high-end GPUs. It places a massive load on Video RAM (VRAM) and modern shader cores. Superposition also includes dedicated tests to evaluate whether a PC is powerful enough to run Virtual Reality (VR) headsets smoothly.
